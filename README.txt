MusicDL Fork
============

Графическое приложение для автоматической загрузки музыки по списку треков (Artist/Title) с выбранных источников. 
Тёмный интерфейс, очередь, прогресс по воркерам, предсканирование уже скачанных файлов, автоповторы при простое и экспорт отчётов.

В проект включены исходники musicdl (папка third_party/musicdl). Поиск и загрузка выполняются через доступные источники musicdl (например Netease, Kuwo, Bilibili, YouTube Music — набор можно выбрать в приложении). Прямые ссылки на файлы не нужны: для каждого трека выполняется поиск по исполнителю и названию, подходящий вариант выбирается автоматически.

Важно
-----
- Приложение ищет треки по строке "Исполнитель + Название" (и при наличии использует длительность для более точного выбора). Гарантировать наличие каждого трека нельзя — зависит от доступности в источниках.
- Некоторые источники/материалы могут быть недоступны в вашем регионе или по сети. При необходимости используйте своё сетевое подключение/VPN. Не обращайтесь к ресурсам, доступ к которым в вашей сети запрещён.
- Соблюдайте законодательство вашей страны и правила/лицензии источников и правообладателей. Используйте программу только для контента, на загрузку и хранение которого у вас есть права.

Требования
----------
- Python 3.10 или новее (рекомендуется 64-bit).
- Windows / Linux / macOS (GUI на customtkinter/tkinter).
- Интернет для поиска и загрузки треков (и, при первом запуске, для установки недостающих Python-пакетов из PyPI, если их нет).
- Для конвертации/обработки аудио используется PyAV (av). FFmpeg отдельно может не требоваться, но наличие корректных кодеков в системе полезно.

Установка и запуск
------------------
1. Распакуйте папку проекта в удобное место (без кириллицы в пути предпочтительнее, но не обязательно).
2. Запуск:
   - Windows: дважды щёлкните "MusicDL-Fork.bat"
   - Любая ОС: выполните в папке проекта
       python launcher.py
     (или: python -m app.main)

Первый запуск (проверка компонентов)
-------------------------------------
При запуске приложение проверяет наличие необходимых компонентов и показывает, что уже установлено, а чего не хватает.
- Разрешение на установку запрашивается ТОЛЬКО для недостающих компонентов. Уже установленные пакеты повторно не запрашиваются и не устанавливаются.
- Если musicdl не установлен, он будет установлен из локальной папки проекта "third_party/musicdl" (после вашего разрешения).
- Остальные зависимости (customtkinter, Pillow, mutagen, av, requests, numpy, certifi и др.) при необходимости устанавливаются через pip (может потребоваться интернет).
- Если всё необходимое уже установлено — приложение запускается без запроса.

При желании зависимости можно установить заранее:
  python -m pip install -r requirements.txt
  python -m pip install ./third_party/musicdl

Как пользоваться
----------------
1. Папка сохранения — выберите, куда сохранять файлы.
2. Файл очереди (активный) — кнопка "Выбрать..." задаёт/переключает CSV-файл очереди, с которым работает приложение.
3. Импорт CSV (с дедупликацией) — добавляет треки из внешнего CSV в ТЕКУЩИЙ активный файл очереди (без смены пути очереди). Дубликаты (по исполнителю+названию) не добавляются.
4. Формат/качество — выберите формат (mp3, m4a, flac, opus, wav) и качество/битрейт.
5. Источники — выберите, какие источники использовать для поиска.
6. Старт — перед загрузкой выполняется быстрое сканирование: уже существующие файлы (по ожидаемому имени в папке сохранения) помечаются как пропущенные (skipped), затем запускаются воркеры загрузки.
7. Пауза/Продолжить — временная остановка и продолжение без полного перезапуска. Стоп — полная остановка (для продолжения нажмите Старт).
8. Повторить failed/miss — вернуть в ожидание треки, которые не удалось скачать или не удалось найти, чтобы попробовать снова.
9. Прогресс: общий прогресс по очереди и отдельная строка состояния/прогресса для каждого воркера (число воркеров задаётся в настройках, применяется при следующем Старт/Стоп→Старт). Активные треки показываются сверху списка очереди.
10. Рестарт при простое — при отсутствии прогресса дольше заданного интервала движок автоматически перезапускается и продолжает очередь (без нажатия Старт вручную, пока загрузка запущена).
11. Экспорт отчёта/M3U — сохраняет report.csv (сводка по всем трекам и статусам) и, при включённой опции, playlist.m3u8 из успешно скачанных треков.
12. Открыть лог — открывает журнал результатов (_jobs/results.jsonl) или лог в папке сохранения.
13. Добавить трек в очередь / Найти сейчас — можно добавить трек вручную, запустить его приоритетно или скачать только его.
14. Последнее успешное скачивание (OK) — время и имя последнего реально скачанного файла (статус OK; пропуски "уже есть" не считаются).

Формат файла очереди (CSV)
--------------------------
Подробно — в файле QUEUE_FORMAT.md. Кратко:
- Кодировка UTF-8 (UTF-8 с BOM поддерживается), колонки: Artist,Title,Album,Seconds
- Title обязателен (или хотя бы Artist/Title). Seconds (длительность в секундах) необязательна, но повышает точность выбора версии.
- Поддерживается импорт распространённых CSV (в т.ч. экспорт Spotify: Track Name, Artist Name(s), Album Name, Duration (ms)) с приведением к нужному формату.

Пример:
Artist,Title,Album,Seconds
Gorillaz,O Green World,Demon Days,275
,Shikanoko Nokonoko Koshitantan,,99

Примечания
----------
- Уже существующие файлы определяются по ожидаемому пути/имени (папка сохранения + шаблон имени + формат). При совпадении и включённом пропуске файл не перекачивается.
- Не рекомендуется запускать два процесса одновременно в одну и ту же папку по одному и тому же списку (возможны гонки на момент скачивания одного и того же ещё неготового трека).
- Ошибки отдельных треков/источников (например, "invalid data found when processing input") означают проблему конкретного файла/версии; можно увеличить число пробуемых кандидатов в настройках и использовать "Повторить failed/miss".
- Настройки сохраняются локально в профиле пользователя.

Лицензии и благодарности
------------------------
Проект использует и включает сторонние компоненты, в том числе musicdl (CharlesPikachu/musicdl) в папке third_party/musicdl — см. лицензии и файлы внутри соответствующих каталогов. Убедитесь, что соблюдаете условия лицензий зависимостей и правила используемых источников.
