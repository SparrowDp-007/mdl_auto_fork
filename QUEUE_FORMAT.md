# Формат файла очереди (CSV)

Файл списка треков — CSV в кодировке **UTF-8** (UTF-8 с BOM тоже поддерживается).

## Колонки
| Колонка  | Обязательно | Описание |
|----------|-------------|----------|
| `Artist` | нет*        | Исполнитель. Можно несколько через запятую. Можно оставить пустым — поиск пойдёт по названию, но точность ниже. |
| `Title`  | да          | Название трека. |
| `Album`  | нет         | Альбом (записывается в теги, если указан). |
| `Seconds`| нет         | Длительность в секундах — помогает выбрать правильную версию при нескольких совпадениях. |

\* Нужен хотя бы `Artist` или `Title`.

## Пример
```csv
Artist,Title,Album,Seconds
Gorillaz,O Green World,Demon Days,275
Кино,Звезда по имени Солнце,Звезда по имени Солнце,225
,Shikanoko Nokonoko Koshitantan,,99
```

## Как ищется и скачивается
- Прямые ссылки на файлы не нужны: поиск выполняется по строке `Artist + Title` в выбранных источниках.
- Из найденных кандидатов автоматически выбирается наиболее подходящий по совпадению исполнителя/названия и близости длительности, с учётом выбранного качества/формата (без ручного подтверждения, прозрачно отображается в статусе/журнале).
- Дубликаты строк (одинаковые Artist+Title по нормализации) при импорте/добавлении отбрасываются.
- Уже скачанные файлы (при включённом «пропускать существующие») не перекачиваются.

## Импорт из Spotify/других CSV
При импорте поддерживаются также распространённые заголовки: `Track Name`, `Artist Name(s)` (разделитель `;`), `Album Name`, `Duration (ms)` — они автоматически приводятся к формату выше.
